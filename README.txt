SETUP
1. Firebase Console: enable Authentication > Google.
2. Create Firestore Database and Storage.
3. Publish firestore.rules and storage.rules.
4. Add your hosted domain to Firebase Authentication > Authorized domains.
5. Serve this folder from hosting/web server, not file://.
6. Google Search Console verification meta tag is already in index.html.
The QR feature uploads the user's own UPI/Google Pay QR image. Account number and IFSC are separate fields.
