# 🧾 Premium GST Bill Maker & Invoice Generator

A modern, premium GST Bill Maker and Invoice Generator built with HTML5, CSS3, Tailwind CSS, Vanilla JavaScript, Firebase Authentication and html2pdf.js.

## ✨ Features

- 🔐 Google Login with Firebase Authentication
- 📱 Mobile-friendly responsive design
- 💻 Premium SaaS-style UI
- 🏢 Seller Details
- 👤 Buyer Details
- 📄 Invoice Details
- 🛒 Dynamic Invoice Items
- 🧮 Automatic GST Calculation
- 🇮🇳 CGST + SGST for intra-state transactions
- 🌐 IGST for inter-state transactions
- 📊 Live Grand Total Summary
- 📥 Professional PDF Invoice Download
- 🧾 Corporate-style TAX INVOICE PDF
- ✍️ Authorized Signatory section
- 🔎 Google Search Console verification support

## 🛠️ Tech Stack

- HTML5
- CSS3
- Tailwind CSS
- Vanilla JavaScript (ES6 Modules)
- Firebase Authentication
- Google Authentication
- html2pdf.js
