# GST Bill Maker

Files:
- index.html
- app.js

Features:
- Direct use; no mandatory login
- One-page A4 GST invoice PDF
- GST 0%, 5%, 12%, 18%, 28%
- CGST + SGST / IGST calculation
- Seller and buyer details
- Optional bank details
- Existing UPI QR upload (no QR generation)
- Logo and signature upload
- Preview and PDF download
- No Firebase database/storage for invoice data

The supplied Google Search Console verification meta tag is included.
